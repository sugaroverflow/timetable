# 2026-08-10 — Activity log goes live (issue #58)

Ed wants to watch the log tick on launch day. Light-touch version:
`LiveLogSync`, a client component in the log page's glass pill, calls
`router.refresh()` every 20s while the tab is visible and immediately
when the tab regains focus — the server component re-renders, new
events appear in place, filters and URL untouched. No new API surface:
polling a server component beats SSE/websockets at this scale (one
admin-ish page, a handful of viewers).

A pulsing green "Live" dot (new `.live-dot` classes, `--green` token)
sits at the pill's end so the behaviour is discoverable. Hidden tabs
pause the polling (the refresh guard checks `visibilityState`).

Deliberately not done: new-row highlight animations (needs client-side
seen-tracking for marginal payoff) and SSE (issue #58 keeps a note if
polling ever feels laggy at real scale).
