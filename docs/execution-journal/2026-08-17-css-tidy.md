# 2026-08-17 — CSS tidy from the pre-prod audit

A globals.css/tokens.css hygiene pass — every item verified by the audit
first, spacing/type-scale questions deliberately left for a product
decision.

## Live bugs

- `var(--border)` was defined nowhere, so `.emoji-choice` (Forum Settings
  emoji picker — including its invisible selected ring's base border) and
  `.mention-menu` (the @mention popup) rendered borderless. Both now use
  `var(--line-strong)`.
- `.cal-fold-avatars .avatar` ringed faces with a literal
  `rgb(255 255 255 / 55%)` — invisible-ish on dark. Now `var(--card)`.
- `.mention-menu`'s `var(--shadow-pop, <literal fallback>)` dropped the
  dead fallback.

## Keyboard focus restorations

- `.rte:focus-within` and `.feed-search:focus-within` get the standard
  ring — the TipTap content area and the search input both set
  `outline: none` with no replacement, so keyboard users lost the ring
  entirely; the wrapper carries it now.
- The toolbar-select ring suppression (QA 2026-08-10) was written as
  `:focus-visible { outline: none }`, which also blanked keyboard focus.
  Rewritten as `:focus:not(:focus-visible)` so only mouse focus is
  suppressed and keyboard focus falls through to the global ring.
- The global `:focus-visible` rule loses its `border-radius: var(--radius-xs)`
  override — outlines follow the element's own radius, and the override
  only stayed harmless by source-order luck. The now-redundant
  `.account-trigger:focus-visible` copy of the global rule is deleted.

## New utilities, adopted app-wide

- `.hint` (`--faint` + `--text-xs`) replaces the 42-site
  `className="faint" style={{ fontSize: 12 }}` pattern; other inline
  style props at those sites survive. The `fontSize: 11/13` variants are
  untouched — they await the type-scale decision.
- `.field-heading` (`--text-sm`) replaces `style={{ fontSize: 13 }}` on
  the `<strong>` form labels in CalendarSetup, DigestSettingsForm,
  EmailDigestForm.
- `.error-text` adopted at the inline `color: var(--red)` sites
  (PersonAdminPanel, SlotSessionControls, TopicManager,
  CreateTimetableForm). Its default size is set via zero-specificity
  `:where(.error-text) { font-size: var(--text-sm) }` so the delete
  buttons that adopt the class keep `.btn`'s own size.
- `.tab-badge` gets a real rule (TopicTabs rendered the class with no
  CSS backing).

## Dead code out

- `.dot`/`.dot.{green,yellow,red}` and the `.cal-row-others` family
  (rule, `:has()` dependent, mobile indent) — markup gone, verified by
  grep.
- tokens.css: `--warning-line` and its only feeders
  `--amber-line`/`--amber-line-d` — consumed by nothing.
- The `.grid-2` name is finally dead: the three `"grid grid-2"` call
  sites drop the token and the comment keeping the name alive is gone.

## Small dedup

- `.status-ready`+`.status-published` and
  `.status-drafting`+`.status-unpublished`+`.status-archived` were
  byte-identical pairs — merged into selector lists, values unchanged.
- `.topic-body-toggle`'s literal `999px` → `var(--radius-pill)`.
